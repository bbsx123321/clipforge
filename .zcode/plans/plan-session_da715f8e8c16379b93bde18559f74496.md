# 麦克风字幕功能（ASR + 三轨编辑器 + 字幕工程文件 + 三方式导出）实施计划

## 已确认决策
- **ASR**：whisper.cpp（whisper-cli.exe）+ 内置 base 量化模型（ggml-base-q5_1，约 58MB），完全离线
- **识别对象**：仅麦克风 —— 改造录制管线，麦克风 PCM 独立落盘 `mic.wav`
- **导出**：烧录进画面 + 独立 .srt + MP4 软字幕轨（mov_text），三者可勾选组合
- **样式**：可设置 —— 黑底白字开关及底色不透明度、文字不透明度、字号（视频高度百分比）、顶部/底部位置、距边缘边距

## 关键事实（探索结论）
- 暂停时音频链不停（record-controller.ts:428 只停视频段），`mic.wav` 将是连续墙钟时间轴，与分段 `startOffsetMs` 同系；首段 offset=0，字幕切区间照抄 mux-audio.ts 的偏移逻辑
- 列表只展示每 session 首段（media-service.ts:72 `segments[0]`）→ 字幕只绑定首段，`cue` 时间 = 首段视频内时间
- 编辑器为控制条窗口切视图（App.tsx:356），非独立窗口；EditProject 目前零持久化 → 本功能顺带用工程文件解决
- WavStreamWriter 参数（48kHz/2ch）不变：mic 链 worklet 同样 outputChannelCount:[2]，识别前转 16kHz mono
- 可照抄模式：ffmpeg-path.ts（外部二进制定位）、runExport（长任务 spawn）、app-settings.ts（JSON 读校验/合并写三件套）、IPC 五步接线、CI 下载 FFmpeg 步骤、--smoke-i18n 流程结构

## 数据流
```
录制：mic getUserMedia → 独立Gain → 第二个chunk-pumper实例 ──IPC audio/mic-chunk──→ mic.wav（与 mix.wav 并行）
停止：finalize 照旧（mix 合入后删）→ mic.wav 保留 → 后台识别任务：
  ffmpeg 切首段区间 mic.wav → 16kHz mono wav → whisper-cli -oj → 解析 JSON → cues
  → 写工程文件 {sessionDir}/screen-001.edit.json（asr:ready）→ 广播进度事件 → 删临时 wav
编辑：双击录像 → 读工程文件 → 恢复剪辑片段+字幕+样式 → 三轨时间轴（视频/波形/字幕）→ 编辑防抖保存
导出：cues 源时间轴→成片时间轴映射（裁剪切分+变速缩放）→ ass(烧录)/srt(文件)/mov_text(软轨)
```

## 工程文件设计（新创，每视频段一份）
`{sessionDir}/{视频段名去扩展}.edit.json`（如 `screen-001.edit.json`）：
```ts
EditProjectFile = {
  version: 1,
  sourceFile: string,                    // screen-001.mp4
  segments: readonly EditSegment[],      // 剪辑片段（一并持久化，解决进度丢失）
  cues: readonly SubtitleCue[],          // { id, startSec, endSec, text }
  style: SubtitleStyle,                  // 字幕样式（编辑器预览与烧录共用）
  waveform: readonly number[],           // 峰值包络（每 0.1s 一点，Int16 归一化 0~1）
  asr: { status: 'pending'|'ready'|'failed'|'none', progress: 0~100, error?: string }
}
```
读写仿 app-settings.ts：逐字段校验、损坏回退默认（空 cues + 初始 segments + 默认样式）。

`SubtitleStyle`（放 shared/types.ts）：
```ts
{ fontSizePct, position: 'bottom'|'top', marginPct, textOpacity, boxEnabled, boxOpacity }
```

## 分阶段实施

### M-A 录制管线：麦克风分离落盘
- `src/renderer/src/audio/capture.ts`：mic source 不再并入 merged，单独 gain → 新 AudioWorkletNode 实例（同 worklet 代码）→ `options.onMicChunk` 回调；stop 断两链
- `src/shared/ipc-channels.ts` + `src/preload/index.ts` + `src/main/ipc.ts`：`audio/mic-chunk` 通道（单向上报，照抄 audio/chunk）
- `src/main/record-controller.ts`：`state.micWav`（仅 captureMicrophone 时创建）；`onMicAudioChunk`；finalize 时 mic.wav **不随 mix 删除**，交给识别任务；`stopRecording` 成功后调用注入的 `onSessionFinalized(rootDir, settings, segments)` 回调（依赖注入，避免主控制器反向依赖字幕服务）
- manifest 不动（mic.wav 是过渡文件，识别完删除）

### M-B whisper 集成与识别服务
- `scripts/download-whisper.sh`：下载 whisper.cpp 官方 Release 的 win64 zip（whisper-cli.exe）+ HuggingFace ggml-base-q5_1.bin → `resources/whisper/`（已存在跳过；`.gitignore` 加 `resources/whisper/`）
- `src/recorder/asr/whisper-path.ts`：resolveWhisperCliPath / resolveWhisperModelPath（照抄 ffmpeg-path：打包 `process.resourcesPath/whisper/`，开发 `resources/whisper/`）
- `src/recorder/asr/whisper-args.ts`：`buildWhisperArgs(modelPath, wavPath, outJsonPrefix, threadCount)` → `-m -f -l auto -oj -of -pp -t`（golden 测试；语言字段实测校准）
- `src/recorder/asr/whisper-run.ts`：spawn + stdout JSON 收集（仿 probeVideo）+ stderr `progress = N%` 解析回调 + 超时（音频时长×6 兜底）+ 退出码判定
- `src/core/subtitles/subtitle-serialize.ts`：`parseWhisperJson(json): readonly SubtitleCue[]`（字段版本差异在实测后锁定，纯函数单测）、`toSrt(cues)`、`toAss(cues, style, videoW, videoH)`
- `src/main/services/subtitle-service.ts`（新子目录，main/ 保持 ≤8 文件）：编排 = ffmpeg 切首段 16k mono wav → whisper → cues 写工程文件 → 清理；`runTranscriptionForSession`；波形计算（从首段 MP4 ffmpeg 提 16k mono pcm，顺序扫描峰值 → waveform 数组写工程文件）；内存 Map 维护进行中任务防重复触发
- IPC：`subtitle/status`(invoke，读工程文件 asr 字段)、`subtitle/run`(invoke，手动/重试)、`subtitle/progress`(event，{sessionId, progress} 广播)；`src/main/index.ts` 解析 whisper 路径入 IpcDeps + 接线 onSessionFinalized（captureMicrophone 且资源齐备才自动跑；失败写 asr:failed 可重试）
- CI（.github/workflows/build.yml）：加下载 whisper-cli + 模型步骤（HF 直连 CI 可行，校验文件存在与大小）；`package.json` extraResources 加 `resources/whisper → whisper`

### M-C 编辑器三轨 + 字幕编辑 + 工程持久化
- `src/shared/types.ts`：SubtitleCue / SubtitleStyle / EditProjectFile / ExportSubtitleOptions（{burn, srtFile, softTrack}）
- IPC：`edit/load`(invoke)、`edit/save`(invoke)——读写工程文件（subtitle-service 内实现）
- `src/renderer/src/components/editor/timeline-math.ts`：从 TimelineTrack 抽出共享换算（pct/clientX→秒/calculateTicks/formatTick）
- `TimelineTrack.tsx` 瘦身为「共享刻度外壳 + 视频轨 lane」；新增：
  - `WaveTrack.tsx`：canvas 画波形（waveform 数组，播放头对齐）
  - `SubtitleTrack.tsx`：cue 块渲染/点击选中/拖动整块/拖左右边（复用 Pointer Capture 模式）/双击空白在播放头处新建
  - `SubtitlesPanel.tsx`：选中 cue 编辑（文本多行输入、入出点秒数、删除、上/下一条）；字幕工具（添加、重新识别、全部清除）；识别状态条（识别中 N% / 无麦克风音频 / 失败重试）
  - `SubtitleStylePanel.tsx`：样式设置（字号滑条 3~8%、位置底/顶、边距 2~20%、文字不透明度、黑底开关+不透明度）——黑底白字为默认
- `EditorView.tsx` 重构（保持 ≤300 行，字幕逻辑下放子组件）：三轨纵向排列（标记行 → 视频轨 → 声音轨 → 字幕轨 → 刻度行）；播放器底部叠加当前 cue 文本层（CSS 按同组样式百分比渲染 = 所见即所得）；工程文件挂载时 load、变更防抖 1s + 关闭时 save；导出选项三开关
- `App.tsx`：onMicChunk 转发；字幕进度事件订阅转发编辑器

### M-D 导出（三方式 + 时间轴映射）

## 风险与对策
- **whisper JSON 字段版本差异**（start/end vs off/off_end）：M-B 第一步本机实测锁定解析（已列入 allowedPrompts 验证命令）
- **FFmpeg subtitles 滤镜 Windows 路径转义**：实测锁定（相对 cwd 或转义盘符冒号），golden 测试固化
- **base 模型中文识别质量/繁简混杂**：先交付实测，质量不足再讨论换 small；-l auto 误判率低
- **识别是 CPU 长任务**：异步后台 + 进度事件 + 不阻塞录制/停止；重复触发用内存任务表防抖
- **EditorView 行数超标**：字幕逻辑全部下放子组件与 hook

## 验收标准
1. 开麦克风录制一段说话 → 停止后编辑器出现字幕轨与可编辑 cues，波形轨正常显示
2. 关麦克风录制 → 编辑器字幕区显示「无麦克风音频」，其余功能不受影响
3. 改字幕文本/时间/样式 → 播放器叠加实时反映；关闭重开编辑器全部恢复（含剪辑进度）
4. 三种导出勾选组合产物正确：烧录画面含字幕、srt 时间对齐成片、mov_text 可开关
5. 单测全绿 + --smoke-subtitle 退出码 0 + CI 打包含 whisper 资源
