# 【存档】C# WinUI 3 技术栈方案

> 状态：已废弃（2026-10-16 改选 Electron 路线）
> 保留原因：领域模型、录制文件协议、阶段划分在 Electron 方案中继续适用；若未来追求原生性能可重启此路线。

---

## 技术栈定案（C# 版）

| 层 | 选型 | 说明 |
|----|------|------|
| 运行时 | .NET 10 (LTS) | 当前长期支持版本 |
| UI 框架 | WinUI 3（Windows App SDK） | Fluent 原生外观，Windows 10 19041+ |
| 架构模式 | MVVM（CommunityToolkit.Mvvm） | 源生成器，样板代码最少 |
| 屏幕捕获 | Windows.Graphics.Capture (WGC) | C# 一等公民，支持窗口/显示器/区域捕获 |
| 视频编码（录制） | Media Foundation SinkWriter | 系统内置 H.264/HEVC 硬编，GPU 纹理直入零拷贝 |
| 视频处理（导出） | FFmpeg 子进程 | 滤镜图（裁剪/拼接/变速/叠加）、GIF/WebM、格式转换 |
| 音频 | NAudio（WASAPI） | 麦克风 + 系统声音 loopback 双路采集与混音 |
| Win32 互操作 | CsWin32（微软官方源生成器） | 低级输入钩子等 P/Invoke |
| 自绘渲染 | Win2D | 时间轴编辑器、录制悬浮条 |

**选型理由**：WGC + Media Foundation 是微软官方推荐的录屏路径，全程 D3D11 GPU 纹理传递（捕获→合成→编码不落内存），CPU 占用最低。FFmpeg 只在「导出/后处理」阶段作为子进程使用。

## 总体分层架构（C# 版）

```
┌─────────────────────────────────────────────────────┐
│  UI 层（WinUI 3 + XAML，MVVM）                       │
│  录制悬浮条 · 工程列表 · 时间轴编辑器（Win2D 自绘）   │
├─────────────────────────────────────────────────────┤
│  应用服务层（C#，ViewModel + Service）               │
│  工程管理 · 录制会话编排 · 导出任务队列 · 消息总线    │
├─────────────────────────────────────────────────────┤
│  领域核心层（纯 C# 类库，无 UI 依赖，可单测）         │
│  ├─ 捕获引擎  WGC 屏幕帧 / WASAPI 音频 / 输入事件    │
│  ├─ 编码引擎  Media Foundation 硬编（录制期）        │
│  ├─ 编辑引擎  时间轴模型 → 帧调度 → 合成指令（纯函数）│
│  └─ 渲染引擎  合成指令 → FFmpeg 滤镜图（纯函数）     │
├─────────────────────────────────────────────────────┤
│  平台层                                              │
│  WGC · Media Foundation · WASAPI(NAudio)            │
│  Win32 低级钩子(CsWin32) · FFmpeg 子进程封装         │
└─────────────────────────────────────────────────────┘
```

## C# 版关键设计

- **录制产物**：`screen.mp4`（近无损、密集关键帧）+ `camera.mp4` + `audio-mix.m4a` + `events.jsonl`（输入事件流）+ `session.json`（元数据与各流时间对齐）。
- **录制管线**：WGC FramePool → D3D11 合成 → MF SinkWriter 硬编（GPU 直通）；NAudio 双路音频混音；低级钩子独立线程写事件流。
- **编辑模型**：`project.json` 时间轴即数据，渲染器纯函数 `Project → RenderPlan`，撤销/重做 = 不可变快照。
- **导出管线**：RenderPlan → FFmpeg filter_complex 滤镜图（纯函数生成 + golden 快照测试）→ 硬编逐级回退。
- **主要风险**：时间轴编辑器 UI 无现成控件，Win2D 全自绘工作量最大。

## C# 版阶段划分

M1 录制 MVP（整屏/区域 + 双路音频 + MF 硬编）→ M2 事件流 + 预览 + 裁剪导出 → M3 时间轴编辑器 → M4 光标特效/缩放动画/GIF → M5 窗口捕获 + 摄像头画中画。
